# Performance Testing Considerations
MTP improves decoding speed but introduces significant variability in performance results. Therefore, when conducting performance tests after modifying components other than MTP itself, MTP must be disabled to ensure consistent and reliable measurements. MTP should only be enabled when specifically testing or optimizing MTP itself.
